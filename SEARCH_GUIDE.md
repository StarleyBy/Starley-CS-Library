# Инструкция по использованию и откату изменений для функции поиска

## Как использовать глобальный поиск

### Шаг 1: Индексация контента
Перед первым использованием поиска или после добавления/обновления книг необходимо создать поисковый индекс.

1.  Убедитесь, что у вас  установлен **Node.js**.
2.  Откройте терминал в корневой папке проекта.
3.  Выполните команду:
    ```bash
    node search/generate-search-index.js
    ```
    Эта команда просканирует все книги и создаст актуальный индекс для поиска.

### Шаг 2: Выполнение поиска
Есть два способа воспользоваться поиском:

1.  **С главной страницы:** Введите ваш запрос в поле поиска вверху страницы и нажмите `Enter`. Вас автоматически перенаправит на страницу с результатами глобального поиска.
2.  **Через страницу поиска:** Нажмите на ссылку **"🔍 Search"** в навигационной панели, чтобы перейти на страницу поиска, и введите ваш запрос там.

## Как удалить все изменения (в случае неудачного деплоя)

**Внимание!** Следующие команды необратимо удалят все незакоммиченные изменения (новые файлы и модификации) и вернут проект к состоянию последнего коммита. Используйте их с осторожностью.

### Вариант 1: Полный сброс всех изменений

Это самый простой и быстрый способ. Он отменит **все** ваши локальные изменения, которые вы ещё не закоммитили.

1.  Откройте терминал в корневой папке проекта.
2.  Выполните команду:
    ```bash
    git reset --hard HEAD
    ```

### Вариант 2: Выборочное удаление

Если вы хотите отменить только изменения, связанные с функцией поиска, и сохранить другие правки.

1.  **Отмените изменения в модифицированных файлах:**
    ```bash
    git checkout -- index.html
    git checkout -- assets/js/app.js
    ```
2.  **Удалите новые файлы и папки:**
    *   Удалите папку `search`.
    *   Удалите папку `node_modules` (если она была создана только для `lunr`).
    *   Удалите файлы `package.json` и `package-lock.json` (если они были созданы только для `lunr`).

Этот вариант сложнее и требует аккуратности. Если вы не уверены, рекомендуется использовать **Вариант 1**.*
