# 📖 Руководство по использованию поиска

## Обзор

Поиск в библиотеке Starley использует **кастомный полнотекстовый алгоритм** с высокой релевантностью, написанный на чистом JavaScript без внешних зависимостей.

### ✨ Возможности

- ✅ **Умная релевантность** - результаты сортируются по множеству факторов
- ✅ **Точный поиск фраз** - распознает точные совпадения запросов
- ✅ **Мультиязычность** - поддержка английского, русского и иврита
- ✅ **Фильтры** - по книге, языку и категории
- ✅ **Подсветка совпадений** - в сниппетах и полном тексте
- ✅ **Пагинация** - удобная навигация по результатам
- ✅ **Кэширование** - быстрый повторный поиск
- ✅ **Debounced ввод** - автоматический поиск при печати

## 🚀 Быстрый старт

### Шаг 1: Генерация поискового индекса

После добавления новых книг или обновления контента:

```bash
node search/generate-search-index.js
```

Эта команда создаст два файла:
- `search/search-index.json` - основной поисковый индекс
- `search/search-config.json` - конфигурация книг и категорий

### Шаг 2: Использование поиска

1. Откройте страницу поиска: **search/search.html**
2. Введите запрос (минимум 2 символа)
3. Нажмите **Enter** или кнопку **Search**
4. Используйте фильтры для уточнения результатов

---

## 🔧 Алгоритм релевантности

Поиск ранжирует результаты на основе:

| Фактор | Вес | Описание |
|--------|-----|----------|
| **Точная фраза** | +100 | Запрос найден как цельная фраза |
| **Длина слова** | +20 | Бонус за более длинные совпадения |
| **Все слова найдены** | +50 | Все термины запроса присутствуют |
| **Процент совпадений** | +30 | Отношение найденных к запрошенным |
| **Плотность (TF)** | +25 | Частота出現 термина в документе |
| **Короткие документы** | +10 | Более короткие тексты приоритетнее |

## 🎯 Советы по эффективному поиску

### ✅ Хорошо

- `heart surgery` - конкретные термины
- `postoperative care` - полные слова
- `аорта коронарный` - русские термины
- `CABG complications` - аббревиатуры

### ❌ Избегайте

- `the and is` - стоп-слова игнорируются
- `a b c` - слишком короткие термины (<2 символов)
- Очень общие запросы без контекста

## 🌐 Поддержка языков

### Автоматическое распознавание

Поиск автоматически определяет язык по символам:
- **Кириллица** (а-я) → русский
- **Иврит** (unicode 0590-05FF) → иврит  
- **Латиница** → английский

### Стоп-слова

Для каждого языка есть свои списки игнорируемых слов:
- **English**: the, a, an, is, are, etc. (~90 слов)
- **Русский**: и, в, не, на, с, по, etc. (~75 слов)
- **עברית**: את, של, על, עם, etc. (~30 слов)

## ⚙️ Технические детали

### Структура индекса

Каждый документ содержит:
```json
{
  "id": "books/icu/bojar|chapter-01|original",
  "bookId": "books/icu/bojar",
  "chapterId": "chapter-01",
  "edition": "original",
  "language": "english",
  "contentLength": 12345,
  "words": {
    "heart": [{"start": 100, "end": 105}, ...],
    "surgery": [{"start": 200, "end": 207}, ...]
  }
}
```

### Позиционный поиск

Индекс хранит **точные позиции** каждого слова, что позволяет:
- Извлекать контекстные сниппеты
- Подсвечивать все вхождения
- Быстро находить точные фразы

### Кэширование

Содержимое документов кэшируется в памяти для:
- Быстрого отображения сниппетов
- Повторного открытия глав
- Сравнения результатов

## 🛠️ Troubleshooting

### Проблема: "Error loading search data"

**Решение:**
```bash
node search/generate-search-index.js
```

### Проблема: Мало результатов

**Возможные причины:**
1. Не сгенерирован индекс
2. Слишком строгие фильтры
3. Опечатки в запросе

**Решение:**
- Очистите фильтры кнопкой "Clear All"
- Проверьте орфографию
- Убедитесь что индекс актуален

### Проблема: Неправильная релевантность

**Это может быть субъективно**, но попробуйте:
- Добавить больше конкретных терминов
- Использовать кавычки для точных фраз (в будущих версиях)
- Проверить что язык определен верно
