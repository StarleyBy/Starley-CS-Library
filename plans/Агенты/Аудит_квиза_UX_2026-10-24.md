# Аудит интерфейса квиза — состояние на 24.10.2026

Получен инструментами `tools/map-functions.mjs` и `tools/check-quiz-i18n.mjs` и чтением функций по карте. Файлы: `quiz.html` (1 308 строк), `assets/js/quiz.js` (10 754 строки), `assets/js/quiz-i18n.js` (414 строк), `assets/css/quiz.css` (3 965 строк).

## 1. Главное

1. **Словарь локализации не используется.** `quiz-i18n.js` содержит 140 ключей на английском и русском (паритет полный), но вызовов `tQuiz(...)` в `quiz.js` и атрибутов `data-i18n*` в `quiz.html` нет. Функция `applyQuizI18n` переключает только кнопки с флагом и рассылает событие `starley:langchange`.
2. **Язык переключается встроенными парами** `isRu ? 'русский' : 'english'`: 454 места в `quiz.js`. Это рабочая схема, но она размазана по всему файлу, и ничто не мешает написать строку только на одном языке.
3. **Смешение языков в разметке.** В `quiz.html` 16 подписей содержат оба языка сразу (список в разделе 3), а навигационные «таблетки» (`📚 Library`, `🔖 Highlights`, `🔍 Search`, `🧠 Quiz`, `📰 Magazine`, `✏️ Editor`, `🛠️ Manifest`) написаны только по-английски, хотя соответствующие русские строки в словаре есть (`navLibrary` и др.). При русском интерфейсе эти надписи остаются английскими. Всего в разметке 200 видимых надписей без `data-i18n`.
4. **Русские строки вне пар (25):** в основном списки названий рангов (L7049–L7194), диалоги администратора и одна строка отчёта в Telegram. Часть из них — данные с английскими двойниками в других местах и в проверке считается известным состоянием.
5. **Язык по умолчанию — русский** в семи местах: три в `quiz.js` (L20, L684, L2770) и четыре в `quiz-i18n.js` (`normalizeLang`, `t`, `applyQuizI18n`). По плану владельца интерфейс квиза должен открываться на английском, поэтому менять нужно во всех семи местах, не сбрасывая уже сохранённый выбор пользователя (`starley_quiz_lang`).
6. **Мобильная вёрстка:** в `<meta name="viewport">` нет `viewport-fit=cover` (поэтому `env(safe-area-inset-*)` не действуют на устройствах с вырезом); `100vh` без запасного `dvh` в L52 и L57 `quiz.css` (`100dvh` есть только в L3040–L3041); `safe-area-inset-bottom` использован один раз (L3701).

## 2. Что уже реализовано (проверено по коду, не ломать)

Таймер сессии (лимит — число вопросов × 60 секунд; фазы по доле времени: до 70% зелёная, 70–90% жёлтая, 90–100% красная, свыше 100% коричневая; звук перехода; пауза по нажатию), пропуск вопроса (в конец колоды), навигация «плеером» (первый, назад, вперёд, последний), калькулятор, черновик и рисование, радар слабых мест (по умолчанию свёрнут), кнопка языка с SVG-флагом, наборы и пресеты в лобби. Не проверено: доля экрана под вопрос на телефоне, начальный выбор дисциплин, общий вид в стиле iOS: нужны глаза в браузере.

## 4. Рекомендуемый порядок

1. **Быстрые победы (низкий риск):**
   - заменить 16 двуязычных подписей и 7 навигационных надписей на `data-i18n` / `data-i18n-title` с ключами словаря (недостающие ключи добавить в `En` и `Ru`);
   - добавить `viewport-fit=cover`, запасной `dvh`, отступы `safe-area` на нижних и верхних панелях;
   - перед правками запустить `node tools/check-quiz-i18n.mjs`, после — `--baseline` (новых находок быть не должно).
2. **Решение владельца по 454 встроенным парам:** либо переносить их в словарь по частям (чище, но много работы), либо ввести единый помощник для пар и запретить строки на одном языке (дешевле), а словарь довести позже. Агент «UX квиза» без этого решения массово строки не переписывает.
3. **Язык по умолчанию — английский (по плану владельца):** поменять во всех семи местах отдельной правкой.
4. После правок `quiz.html`, `quiz.js`, `quiz.css` — проверка `node tools/check-sw-shell.mjs` и решение «Хранителя кэша» по версии (файлы входят в оболочку PWA).
