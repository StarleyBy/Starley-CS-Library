## 4. Что не проверялось

- Изображения: картинки хранятся в облаке и в git не попадают, поэтому наличие файлов (I001, предупреждение) проверено только на искусственных данных. На вашей машине проверка включится для тех манифестов, рядом с которыми есть папка `images/` (`<папка книги>/quiz/images/`).
- Правильность ответов по источникам — это работа «Квиз-Верификатора», скрипт её не проверяет.
- Повторы формулировок между файлами (≈ 660 групп) — по замыслу: вопросы из сборников SEATS копируются в тематические квизы. Скрипт отслеживает только повторы внутри файла (133 случая); часть из них может быть законной (разные картинки к одной формулировке) и требует просмотра.
