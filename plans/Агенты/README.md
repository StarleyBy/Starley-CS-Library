# plans/Агенты

Здесь лежат планы развития системы агентов и архив прежних инструкций.

- `План_агентов.md` — план: глобальные и локальные агенты, приоритеты, волны внедрения.
- `Аудит_глав_2026-10-23.md` — исходное состояние глав по результатам `validate-chapters.mjs`.
- `Аудит_квиза_2026-10-23.md` — исходное состояние манифестов квиза и таксономии по результатам `validate-quiz.mjs`.
- `Аудит_PWA_2026-10-24.md` — состояние Service Worker, оболочки и дисциплины подъёма версии кэша.
- `Аудит_квиза_UX_2026-10-24.md` — состояние интерфейса и локализации квиза.
- `Аудит_репозитория_2026-10-25.md` — размер и история, секреты, лишнее в git и на сайте.
- `Аудит_каталога_2026-10-26.md` — согласованность `library.json`, `metadata.json` и файлов глав.
- `Аудит_Supabase_2026-10-26.md` — безопасность серверной части (политики доступа, функции, вход по PIN).
- `архив/` — прежние инструкции агентов и черновые копии (только для истории).

**Источник правды по агентам — `.agents/skills/*/SKILL.md` и `/AGENTS.md`.** Файлы из `архив/` не обновляются и не используются агентами.
