1. Краткое описание задачи
Внедрение системы типографических пресетов (Modern, Academic, Technical, Accessibility) в режим чтения PWA-приложения Starley-CS-Library. Необходимо заменить текущее точечное переключение системных шрифтов на комплексные стили (заголовки, текст, подписи), обновить UI радиального меню для выбора стилей и обеспечить высокую производительность загрузки без смещения контента (CLS).

2. Анализ текущей реализации
*   **Архитектура**: Vanilla JS PWA, стилизация через CSS-переменные, хранение настроек в `localStorage`.
*   **Затрагиваемые модули**: DOM-контейнер режима чтения, компонент радиального меню, система управления темами, CSS-ядро ридера.
*   **Ограничения**: Изменение шрифтов вызывает пересчет высоты строк (Layout Shift), что критично для позиции чтения (особенно при виртуальном скроллинге). Добавление большого количества шрифтов может замедлить первую отрисовку (FCP/FOIT).

3. Итоговое техническое решение
Вместо разрозненного выбора гарнитур реализуем **Типографические пресеты**.
*   **Производительность (Frontend)**: Используем вариативные шрифты (Variable Fonts) в формате WOFF2 с сабсеттингом (Cyrillic, Latin, Math) и `font-display: swap`. Главный шрифт (Inter) предзагружается, остальные загружаются лениво.
*   **Интерфейс (UX/UI)**: В радиальном меню кнопка «Шрифт» заменяется на «Стиль». По клику меню переходит в состояние подменю (раскрывает 4 сектора по углам 45°, 135°, 225°, 315° с иконками пресетов), исключая слепое циклическое переключение.
*   **Управление стилями (Architecture)**: Смена пресета устанавливает атрибут `data-typography-preset` на `.reader-container`. CSS-переменные (`--rd-font-h1`, `--rd-font-body` и т.д.) переопределяются на уровне этого селектора.
*   **Предотвращение CLS (QA/Frontend)**: При смене пресета JS вычисляет `getBoundingClientRect()` текущего видимого якоря/абзаца и корректирует `scrollTop` после применения новых стилей.

4. План реализации

**Этап 1: Подготовка и оптимизация ассетов**
*   **Цель**: Сформировать минималистичный набор шрифтовых файлов.
*   **Исполнитель**: UI Designer / Frontend Developer.
*   **Файлы**: Директория `assets/fonts/`.
*   **Изменения**: Подготовить WOFF2 файлы вариативных шрифтов Inter и Lora, а также статических JetBrains Mono и Atkinson Hyperlegible. Провести сабсеттинг, удалив неиспользуемые глифы (иероглифы и т.д.).
*   **Зависимости**: Нет.

**Этап 2: Обновление CSS-архитектуры**
*   **Цель**: Внедрить систему токенов для пресетов.
*   **Исполнитель**: Frontend Developer.
*   **Файлы**: `assets/css/reader.css`
*   **Изменения**:
    1. Добавить `@font-face` с `font-display: swap` и параметром `size-adjust` для выравнивания метрик с системным шрифтом.
    2. Создать корневые переменные по умолчанию (стиль Modern).
    3. Добавить селекторы `[data-typography-preset="academic"]`, `[data-typography-preset="technical"]`, `[data-typography-preset="accessibility"]` с переопределением переменных (`--rd-font-h1`, `--rd-font-body`, `--rd-weight-h1`, `--rd-line-height`).
    4. Настроить `transition: font-family 0.3s ease, font-size 0.3s ease` для плавной смены.
*   **Зависимости**: Этап 1.

**Этап 3: Модификация логики радиального меню**
*   **Цель**: Реализовать двухуровневое радиальное меню.
*   **Исполнитель**: Frontend Developer.
*   **Файлы**: `assets/js/radial-menu.js`
*   **Изменения**:
    1. Добавить поддержку состояний (state machine) в меню (Main -> Typography).
    2. Реализовать логику отрисовки 4 подкнопок при выборе раздела "Типографика" (по углам 45°, 135°, 225°, 315°).
    3. Центральная кнопка меняет иконку на "Назад".
    4. Привязать вызов `TypographyManager.setPreset(id)` на клики по подкнопкам.
*   **Зависимости**: Этап 2.

**Этап 4: Разработка логики применения и сохранения пресетов**
*   **Цель**: Обеспечить работу с DOM, сохранение выбора и защиту от CLS.
*   **Исполнитель**: Frontend Developer.
*   **Файлы**: `assets/js/reader.js`, `assets/js/settings.js`
*   **Изменения**:
    1. Создать класс/объект `TypographyManager`.
    2. В методе `setPreset`:
        * Найти первый видимый элемент в `.reader-container` и сохранить его смещение относительно окна.
        * Установить `data-typography-preset` на `.reader-container`.
        * Сохранить `id` в `localStorage.setItem('reader_typography_preset', id)`.
        * Пересчитать `scrollTop` контейнера, чтобы сохраненный элемент остался на той же позиции.
    3. В `settings.js` добавить загрузку пресета из `localStorage` при инициализации страницы.
*   **Зависимости**: Этапы 2 и 3.

**Этап 5: Добавление предзагрузки в HTML**
*   **Цель**: Устранить FOIT для дефолтного пресета.
*   **Исполнитель**: Frontend Developer.
*   **Файлы**: `reader.html`
*   **Изменения**: Добавить `<link rel="preload" href="assets/fonts/inter-var.woff2" as="font" type="font/woff2" crossorigin>` в `<head>`.
*   **Зависимости**: Этап 1.

7. Удаляемые файлы
Не требуются. Старые системные резервные шрифты (fallback) остаются в стеке CSS.

8. Изменения архитектуры
*   Отказ от прямого инлайнового изменения `font-family` у элементов.
*   Переход на паттерн **Data-Attribute State**: всё визуальное состояние ридера управляется одним дата-атрибутом на корневом узле.
*   Радиальное меню трансформировано из плоского списка экшенов в иерархический компонент с поддержкой уровней вложенности.

9. План тестирования
*   **UI/Visual**: Проверить отсутствие наслоений текста, обрезания выносных элементов шрифтов (особенно в `jb-mono` и `lora`) и отображение математических символов/лигатур во всех 4 пресетах.
*   **Functional**: Сменить пресет -> обновить страницу (F5) -> убедиться, что пресет сохранился.
*   **UX (CLS Check)**: Проскроллить статью до середины, сменить пресет с Modern на Academic. Убедиться, что строка, на которой находился взгляд, осталась на экране, а страница не "прыгнула".
*   **Mobile & Accessibility**: Убедиться, что на разрешении 320px подменю радиального меню помещается в экран, размер таргет-зон не менее 44x44px.
*   **Performance**: Проверить в Network вкладке, что загрузка `lora`, `jb-mono` и `atkinson` происходит только при их выборе, а `inter` грузится сразу (размер шрифтов < 300KB в сумме).

10. Критерии завершения
Задача считается выполненной, если:
✓ Доступны 4 типографических пресета (Modern, Academic, Technical, Accessibility).
✓ При переключении пресетов не возникает сдвига позиции чтения (скомпенсирован Layout Shift).
✓ Радиальное меню корректно открывает подменю стилей и поддерживает возврат на главный уровень.
✓ Выбор пользователя персистентен и корректно применяется после перезагрузки страницы.
✓ Новые шрифты не блокируют отрисовку страницы при медленном соединении (работает `font-display: swap`).
✓ Код, таблицы и формулы отображаются корректно во всех пресетах (отсутствуют missing glyphs).

11. Возможные улучшения
*   **Тонкая настройка Variable Fonts**: Добавить в подменю радиального меню ползунок "Weight", который будет напрямую менять `font-variation-settings: 'wght'` для текущего пресета, позволяя пользователям делать текст тоньше или жирнее без загрузки новых файлов.
*   **Адаптация под темную тему**: При включении темного режима программно снижать `--rd-weight-h1` и `--rd-weight-body` на 50 единиц (для вариативных шрифтов) для предотвращения визуального "заплывания" светлых букв на черном фоне (halatian effect).
