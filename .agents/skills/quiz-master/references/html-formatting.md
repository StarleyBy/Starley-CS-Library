# Стандарт HTML-оформления пояснений квиза

Справочник к `quiz-master/SKILL.md`. Читать при написании `explanationEn` и `explanationRu`.

## Что реально используется в существующих манифестах (анализ 3 219 вопросов)

Теги в пояснениях: `<b>`, `<br>`, `<span style="...">`, `<li>`, `<ul>`, `<ol>`, `<mark>`, `<h3>`, `<p>`, `<i>`. Заголовки разделов — `<h3>` с эмодзи-маркером, например `<h3>🎯 Correct Answer</h3>`; текст — в `<p>`, перечисления — в `<ul>/<ol>`, ключевые слова — `<b>`.

Цвета непринципиальны (подтверждено владельцем): важно, чтобы выделение было и роль цвета сохранялась. Оттенки ниже — значения по умолчанию для нового контента; там, где в данных нет устойчивого значения, предложен свой оттенок.

Цвета в `<span style="...">` (самые частые значения):

| Смысл (по стандарту) | Как встречается в данных | Рекомендация для нового контента |
|---|---|---|
| Красный: опасные структуры, осложнения, рискованные приёмы | `color:#e74c3c` (≈ 900), `color: #e74c3c;`, реже `red`, `#FF0000` | `<span style="color:#e74c3c">…</span>` |
| Синий: важная анатомия и физиологические структуры | `color:#3498db` (≈ 340), `#007bff` | `<span style="color:#3498db">…</span>` |
| Фиолетовый: важные определения | `color:#800080` (≈ 130), `#9b59b6` | `<span style="color:#9b59b6">…</span>` |
| Зелёный: рекомендации гайдлайнов (фон) | `#2ecc71` (текст), `#00FF00` (текст) | `<span style="background-color:#c8e6c9;color:#000000">…</span>` |
| Жёлтый фон: единственный самый важный экзаменационный факт | `background-color: #FFFF00; color: #000000;` (≈ 155), `#ffffcc` | `<span style="background-color:#FFFF00;color:#000000">…</span>` |
| Оранжевый: операционные советы | устойчивого значения не найдено | `<span style="color:#e67e22">…</span>` |
| Голубой (cyan) фон: ориентиры | устойчивого значения не найдено | `<span style="background-color:#b2ebf2;color:#000000">…</span>` |
| Розовый фон: редкие, но классические концепции (редко) | устойчивого значения не найдено | `<span style="background-color:#f8bbd0;color:#000000">…</span>` |

Тег `<mark>` (≈ 3 000 вхождений) тоже применяется для выделения; в новом контенте используй его в тех же ролях, что и ближайшие вопросы того же манифеста.

## Правила

- Выделяй слова и короткие фразы, не абзацы целиком.
- Единственное жёлтое выделение на пояснение — для самого важного экзаменационного факта.
- Не смешивать форматы кавычек и записей стиля внутри одного пояснения: либо `style="color:#e74c3c"`, либо `style='color: #e74c3c;'` (в новом контенте — двойные кавычки без пробела).
- Теги закрывать; проверка Q010 ловит нарушенный баланс.
- Эмодзи — только как маркеры разделов из набора 🎯 🔬 🫀 🔪 ⚠️ ❌ 📚 🚨 🔥 🧠 💡 📜 🛠️ ✅.
- Сноски-цитаты `[1]`, `[2,4]` запрещены.

## Рекомендуемая структура пояснения

```html
<h3>🎯 Correct Answer</h3>
<p>The correct answer is <b>D: type IIIb</b>.</p>
<h3>🔬 Why It Is Correct</h3>
<p>…механизм и логика…</p>
<h3>❌ Why the Other Options Are Incorrect</h3>
<ul>
  <li><b>A:</b> чем правдоподобен — почему неверен</li>
  <li><b>B:</b> …</li>
</ul>
<h3>📚 Board Pearl</h3>
<p><span style="background-color:#FFFF00;color:#000000">Самый важный экзаменационный факт</span></p>
<h3>✅ Take-home Message</h3>
<p>Одна короткая итоговая фраза.</p>
```
В русском пояснении — те же разделы и та же буква ответа. Разделы «Мнемоника» (🔥) и «Клиническая жемчужина» (🚨) добавляются, только если действительно полезны.
