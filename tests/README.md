# Тестовая песочница и набор тестов Starley Medical Library

Данный каталог является **выделенной рабочей зоной агента «Кодер»** для проведения отладки, модульного тестирования, нагрузочных тестов и валидации функционала приложения.

## Структура каталога

- `tests/unit/` — постоянные модульные тесты ключевых компонентов (поиск, квиз, ридер, гайдлайны).
- `tests/sandbox/` — временная рабочая папка для разовых скриптов отладки, дампов и экспериментов (содержимое удаляется после завершения отладки).
- `tests/run-all.mjs` — единый раннер для запуска всех проверочных тестов перед сдачей работы.

## Правило агента «Кодер»
> Все проверочные скрипты, временные файлы данных и тестовые сценарии создаются **строго внутри каталога `tests/`**.  
> Запрещено создавать тестовые и временные файлы (`test.js`, `temp.json`, `debug.mjs`) в корне проекта или в рабочих папках (`assets/`, `search/`, `data/`).
